### Mod allows you to change the number of attribute points and skill points granted upon leveling up.
### It works without any issues in the campaign, however, in "freegame" mode, you must edit your character in the editor (https://github.com/Spellforcawka/SpellForce-Freegame-Save-Editor) and click the "bypass player data validation" button—otherwise, a "player data corrupted" error will occur when loading your character.
### After the game is launched for first time, a .txt file is generated in which you can change the number of points awarded.
## Default config:
### AbilityPoints=2
### StatPoints=5
