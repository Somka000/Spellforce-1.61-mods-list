Here are mods for SpellForce 1.61 (public test) in .asi and/or .sfm format, source code is often also included. I created most of the mods, but there are also mods from other devs here.
To download a mod:
- for the vanilla version, download the .asi file
- for the version with SFSF, download the .sfm file

If you want to submit any mod, please create a PR, source code is welcome.
